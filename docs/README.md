# SolidGuard Technical Documentation & Viva Guides

This directory contains research notes, empirical evaluations, mathematical proofs, and comprehensive defense materials for the SolidGuard project.

---

### Key Documentation Files
- **`VIVA_DEFENSE_AND_PROOFS.md`**  
  Comprehensive Viva Defense Preparation Guide. Covers anticipated examiner questions, 100K benchmark mathematical formulations, Gini impurity calculations, and holdout validation proofs.

- **`ACCURACY_IMPROVEMENT_REPORT.md`**  
  Detailed analysis of the stepwise accuracy evolution from Phase 1 baseline (85.93%) through the Phase 4 100K balanced ensemble (95.80%).

- **`accuracy_analysis.md`**  
  Empirical comparison across 8 different feature balancing and classification strategies.

- **`final_report.md`**  
  Comprehensive chronological development report capturing model iterations and architectural decisions.

- **`problem_and_solution.md`**  
  Technical problem definition covering EVM execution hazards, the immutability paradox, and SolidGuard's dual-tier static arbitration solution.

- **`project_review.md`**  
  Exhaustive technical review and gap analysis of the static feature extraction pipeline.
